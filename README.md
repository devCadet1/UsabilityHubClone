UsabilityHub – Landing Page Clone

A responsive UsabilityHub-inspired landing page built to practice modern frontend development, responsive layouts, semantic HTML, CSS styling, navigation components, image handling, and UI design.

🔗 Live Demo: https://devcadet-usabilityhub.netlify.app/

📌 Project Overview

This project is a frontend implementation of a UsabilityHub-style user research and usability testing platform landing page.

The website presents UsabilityHub as a remote user research platform that helps teams validate design decisions using feedback from real users.

The landing page focuses on:

Product introduction
User research methodologies
Feature discovery
Customer/audience targeting
Call-to-action sections
Navigation and footer links
Responsive visual presentation

The original landing-page content describes UsabilityHub as a platform for validating design decisions with real users.

🧰 Features / Methodologies

The website presents several usability-testing methodologies.

Card Sorting

Allows teams to understand how users naturally group and label information.

Use case:

Information architecture
Navigation structure
Website categorization
Prototype Testing

Allows users to interact with and evaluate prototypes.

The page specifically mentions testing navigation through Figma prototypes.

Use case:

UX validation
User flows
Prototype evaluation
First Click Tests

Tests whether users make the expected first interaction when attempting to complete a task.

Use case:

Navigation testing
Interaction testing
Task completion analysis
Design Surveys

Allows teams to collect feedback on:

Images
Videos
Audio
Other design assets

Use case:

Visual feedback
Design validation
User opinions
Preference Tests

Helps determine which design users prefer and understand why they prefer it.

Use case:

A/B-style design comparison
UI decisions
Visual design validation
Five Second Tests

Tests the user's first impression of a design by evaluating what they understand after seeing it for a short period.

Use case:

Landing pages
Branding
Messaging
Visual hierarchy

🔍 Example Use Cases
